# Фирменные шрифты

Поместите файлы шрифтов в эту папку:

## CeraPro (для меню)
- `CeraPro-Regular.woff2`
- `CeraPro-Regular.woff`
- `CeraPro-Regular.ttf`

## HelveticaNeueCyr (для текста)
- `HelveticaNeueCyr-Roman.woff2`
- `HelveticaNeueCyr-Roman.woff`
- `HelveticaNeueCyr-Roman.ttf`

### Поддерживаемые форматы:
1. **WOFF2** (предпочтительно) - лучшая компрессия
2. **WOFF** - хорошая компрессия
3. **TTF** - резервный вариант

### Если у вас другие имена файлов:
Обновите пути в `app/globals.css` в секции `@font-face`.

### Альтернатива (если нет файлов):
Если у вас нет файлов шрифтов, можно использовать похожие шрифты через Google Fonts или другие источники. Обновите `@font-face` в `globals.css`.
