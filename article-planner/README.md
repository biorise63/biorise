# Article Planner

Локальный веб-планнер для SEO-статей.

## Что умеет

- хранит список статей в `data/articles.json`;
- показывает, что уже заполнено: keyword, Title, Description, H1, URL;
- позволяет редактировать структуру статьи, внутренние ссылки и заметки;
- содержит один ручной чекбокс: `Статья опубликована`;
- стартует локально и не связан с продакшен-сайтом.

## Как запустить

Из корня проекта:

```bash
node article-planner/server.js
```

Открыть в браузере:

```text
http://localhost:3077
```

## Где лежат данные

```text
article-planner/data/articles.json
```

Этот файл можно редактировать как через интерфейс, так и вручную.

## Контент-карта

Для кластерного SEO-планирования рядом хранится отдельная карта тем:

```text
article-planner/data/content-map.json
```

Она собирается из:

- текущих страниц капельниц;
- страницы анализов;
- страницы чек-апов;
- опубликованных статей из `out/articles`.

Обновить карту можно командой:

```bash
node article-planner/generate-content-map.js
```

Этот файл нужен как опорная база для масштабирования контента без дублей: вокруг каждой услуги и диагностического направления в нем заранее собраны безопасные supporting-углы для новых статей.
