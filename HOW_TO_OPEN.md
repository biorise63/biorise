# Как открыть сайт БЕЗ сервера

## ✅ Простой способ - просто откройте HTML файл!

После выполнения `npm run build` создается папка `out/` со всеми HTML файлами.

### Способ 1: Прямо в браузере (может не работать полностью)

1. Найдите файл: `out/index.html`
2. Дважды кликните на него
3. Откроется в браузере

⚠️ **Внимание**: Могут быть проблемы с путями к файлам (CSS, JS, изображения), так как браузер использует `file://` протокол.

### Способ 2: Простой локальный сервер (рекомендуется)

Если просто открыть HTML не работает, используйте встроенный Python сервер:

```bash
cd out
python3 -m http.server 8000
```

Затем откройте в браузере: `http://localhost:8000`

Или используйте Node.js:

```bash
npx serve out
```

### Способ 3: Просто перетащите папку `out/` в браузер

Некоторые браузеры могут открыть папку напрямую.

## 📁 Где находятся файлы?

После `npm run build`:
- `out/index.html` - главная страница
- `out/_next/` - CSS и JS файлы
- `out/` - все остальные файлы

## 🔄 Обновление сайта

Каждый раз, когда вы меняете код:

1. Выполните `npm run build`
2. Откройте `out/index.html` (или используйте локальный сервер)

## 💡 Почему нужна сборка?

Next.js использует React и современные технологии, которые нужно "скомпилировать" в обычные HTML/CSS/JS файлы, которые понимает браузер.

Это как:
- **Исходный код** (TypeScript, React) → **Сборка** → **Готовые HTML файлы**

Аналогия: вы не можете запустить `.psd` файл Photoshop напрямую - нужно сначала экспортировать в `.jpg`.

## ✅ Итого:

**Для разработки** (чтобы видеть изменения сразу):
```bash
npm run dev
```

**Для просмотра готового сайта** (просто HTML файлы):
```bash
npm run build
# Затем откройте out/index.html
```

**Для деплоя на Vercel/GitHub**:
Просто загрузите код на GitHub, Vercel сам соберет!
