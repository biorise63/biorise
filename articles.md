# ТЗ для создания SEO-статей

## Задача

Создавать экспертные SEO-статьи, которые полно и понятно отвечают на запрос пользователя, соответствуют тематике сайта и аккуратно направляют читателя на релевантные внутренние страницы: услуги, анализы, товары или связанные материалы.

Статья должна быть написана для человека, а не представлять собой набор ключевых слов.

## Что должно быть включено в статью

1. SEO Title длиной примерно 50–70 символов.
2. Один заголовок H1, содержащий основной поисковый запрос в естественной форме.
3. Meta Description длиной примерно 130–170 символов.
4. Короткое вступление, которое сразу отвечает на основной вопрос пользователя.
5. Логичная структура с заголовками H2 и при необходимости H3.
6. Подробное раскрытие темы без воды и повторов.
7. Ответы на основные смежные вопросы пользователей.
8. Блок FAQ из 3–6 вопросов, если он действительно полезен для темы.
9. Краткий вывод без повторения всей статьи.
10. Уместный призыв перейти на услугу, записаться или ознакомиться с предложением сайта.

## Требования к SEO

- Основной ключевой запрос использовать в Title, H1, вступлении и одном из подзаголовков.
- Дополнительные запросы и синонимы распределять по тексту естественно.
- Не повторять одну ключевую фразу слишком часто.
- Не использовать неестественные формулировки только ради частотности.
- Не создавать абзацы, не несущие практической пользы.
- Каждый раздел должен отвечать на конкретный вопрос пользователя.
- Не указывать гарантии результата, если их невозможно подтвердить.
- Не копировать тексты конкурентов и другие страницы сайта.
- Избегать канцелярита, сложных конструкций и рекламных штампов.

## Внутренняя перелинковка

В одной статье должно быть не более 3–4 внутренних ссылок.

Каждая ссылка должна:

- соответствовать контексту абзаца;
- вести на реально существующую страницу сайта;
- быть полезной пользователю;
- размещаться внутри естественной фразы;
- иметь понятный анкор;
- не дублировать другую ссылку на ту же страницу без необходимости.

Не размещать несколько внутренних ссылок подряд в одном предложении или абзаце.

Не использовать анкоры:

- «тут»;
- «здесь»;
- «по ссылке»;
- «подробнее» без пояснения;
- наборы ключевых слов;
- неестественные коммерческие фразы.

Использовать естественные анкоры:

- «капельница железа»;
- «анализ на ферритин»;
- «консультация врача»;
- «анализы при дефиците железа»;
- «стоимость процедуры».

### Пример перелинковки

Если статья посвящена капельницам железа, в тексте должна быть уместная ссылка на страницу услуги:

> При подтверждённом дефиците врач может рассмотреть внутривенное введение препарата. Узнать, как проходит [капельница железа](/services/kapelnitsa-zheleza/), можно на странице услуги.

Если в статье говорится о необходимости проверить ферритин, ссылка должна быть встроена непосредственно в подходящую фразу:

> Для оценки запасов железа врач может назначить [анализ на ферритин](/analizy/ferritin/).

Ссылка не должна выглядеть вставленной искусственно ради SEO.

Перед написанием статьи необходимо проверить список доступных внутренних страниц, карту сайта или переданный список URL.

Запрещено придумывать адреса страниц. Если подходящий URL неизвестен, использовать пометку:

`[НУЖНА ССЫЛКА НА УСЛУГУ: название страницы]`

## Правила для медицинских статей

- Не ставить диагноз.
- Не назначать лечение от имени врача.
- Не давать универсальные схемы приёма препаратов и дозировки.
- Не утверждать, что процедура подходит всем.
- Не использовать формулировки «абсолютно безопасно», «без противопоказаний», «гарантированно помогает».
- Указывать, что решение принимается врачом после оценки жалоб, анамнеза и результатов обследований.
- Объяснять возможные противопоказания, ограничения и ситуации, когда требуется медицинская помощь.
- Все медицинские утверждения должны быть точными и проверяемыми.
- При необходимости добавить нейтральный дисклеймер:

> Материал носит информационный характер и не заменяет консультацию врача.

## Стиль текста

- Писать на понятном русском языке.
- Использовать короткие абзацы по 2–5 предложений.
- Не начинать статью с общих фраз вроде «здоровье — самое ценное».
- Не злоупотреблять списками.
- Не повторять одинаковую мысль разными словами.
- Не писать от лица врача, если автор статьи не указан как врач.
- Сохранять спокойный, экспертный и доброжелательный тон.
- Не запугивать читателя и не использовать агрессивные продажи.

## Формат результата

Выдать материал в следующем порядке:

1. Основной поисковый запрос.
2. Дополнительные запросы.
3. Title.
4. H1.
5. Meta Description.
6. URL страницы.
7. Текст статьи с H2 и H3.
8. Внутренние ссылки, встроенные в текст.
9. FAQ.
10. Краткий список использованных внутренних страниц.

## Проверка перед публикацией

Перед завершением убедиться, что:

- Title и H1 не дублируют друг друга дословно без необходимости;
- основной запрос раскрыт полностью;
- нет переспама ключевыми словами;
- в статье не более 3–4 внутренних ссылок;
- все ссылки релевантны контексту;
- URL не были придуманы;
- ссылки не ведут на одну страницу несколько раз без причины;
- медицинские утверждения не выглядят как индивидуальные назначения;
- статья не конкурирует по смыслу с уже существующей страницей сайта;
- текст можно опубликовать без дополнительного SEO-редактирования.
